# Branding and naming

“Agent Effects Testkit” is a **provisional working name** selected for this
starter. No trademark opinion or guaranteed package/repository availability is
provided.

Before public release:

1. recheck PyPI, GitHub, npm, major search engines, and relevant trademark
   databases;
2. avoid names that imply affiliation with an existing framework or vendor;
3. reserve package, repository, documentation, and social identifiers together;
4. add the real repository URL to package metadata and `CITATION.cff` only after
   the remote exists;
5. document the final command and import-name migration if they change.

The technical identity should survive a rename:

> Property-based transaction testing for side-effecting AI agents: commit-aware
> faults, deterministic outcome contracts, and reduced counterexamples.
